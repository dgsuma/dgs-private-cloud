# Evidence

Use this directory only for sanitised evidence such as:

- redacted installation screenshots,
- redacted storage screenshots,
- command-output text files with no secrets,
- diagrams that cannot be expressed in Mermaid.

Do not commit screenshots that expose:

- IMSI,
- ICCID,
- mobile number/MSISDN,
- passwords,
- tokens,
- public WAN details,
- browser cookies or sessions,
- private keys,
- QR codes.

Recommended naming:

```text
YYYY-MM-DD-short-description.png
YYYY-MM-DD-command-output.txt
```

Keep unredacted evidence outside Git.
